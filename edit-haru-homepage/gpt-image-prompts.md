# 제철 과일 배너용 GPT 이미지 만들기

지금 배너의 과일은 직접 그린 그림이에요. GPT 이미지로 바꾸려면 아래 여섯 장을 만들어 `img/` 폴더에 넣고,
`index.html`의 `<main id="main">`에 `data-photos="img/"`를 추가하면 자동으로 사진으로 바뀌어요.
과즙이 튀는 움직임은 그대로 위에 겹쳐서 나와요.

- 크기: 정사각형 1024×1024 이상, WebP
- 배경: 모두 같은 짙은 초록(#16291f) 단색, 과일은 가운데, 글자·소품 없음

| 파일 이름 | 프롬프트 |
|---|---|
| `gamgyul-whole.webp` | 잎이 한 장 달린 잘 익은 감귤 한 개, 짙은 초록(#16291f) 단색 배경 가운데, 부드러운 측면 조명, 차분한 프리미엄 식품 사진, 글자 없음 |
| `gamgyul-burst.webp` | 같은 감귤이 반으로 갈라지며 단면이 보이고 주황색 과즙 방울이 사방으로 튀는 순간, 고속 촬영, 같은 배경과 조명, 글자 없음 |
| `apple-whole.webp` | 잎이 달린 빨간 부사 사과 한 개, 같은 배경과 조명, 글자 없음 |
| `apple-burst.webp` | 같은 사과가 반으로 갈라지며 단면과 씨가 보이고 맑은 과즙 방울이 튀는 순간, 고속 촬영, 같은 배경과 조명, 글자 없음 |
| `dangam-whole.webp` | 꼭지가 달린 단감 한 개, 같은 배경과 조명, 글자 없음 |
| `dangam-burst.webp` | 같은 단감이 반으로 갈라지며 단면이 보이고 주황색 과즙 방울이 튀는 순간, 고속 촬영, 같은 배경과 조명, 글자 없음 |

과일을 바꾸려면 `index.html`의 `data-fruit` 값과 파일 이름 앞부분을 같게 맞추면 돼요.
